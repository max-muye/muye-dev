LocalTalk

How LocalTalk works.

September 11, 2026

LocalTalk is the chat space at /talk. It is meant to feel quick, local, and low-friction: open a room, say something, share a file, and move on.

Rooms

The main room lives at /talk. Other rooms can live under their own paths, so a small group can use a separate place without needing a whole new app.

Signed Chat

The signed room uses Clerk sign-in. It can show a user button, remember a display name, and support private messages between signed-in people.

Files And Messages

Text messages can include links and code blocks. Files can be uploaded and downloaded from the room, with simple duplicate protection so one action does not accidentally send twice.

Moderation

The admin page can remove messages, name devices, ban devices or IPs, manage text bans, and control fast-spam protection. The public lock button was removed so the chat stays simpler.

Language

LocalTalk follows the master language switch on the main site. When the master language is Chinese, LocalTalk uses Chinese; otherwise it stays in English.
