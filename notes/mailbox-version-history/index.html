Mailbox

Mailbox version history.

September 19, 2026

Muye mail is the mailbox system at /mailbox. It receives mail for @muye.dev, stores messages, and lets Muye send mail from the site.

v2.5.0

  • Quote an inbox or outbox message into a new reply.
  • Attach and send up to five files in one message, with a combined 4 MB limit.
  • Open both new multi-file messages and older single-file messages.

v1.0.0

  • Mailbox sign-in with a Muye email and password.
  • Inbox, outbox, trash, message preview, and file attachments.
  • Incoming mail stored through Cloudflare Email Routing and D1.
  • Outgoing mail sent through Resend when configured.
  • Email-only password reset using verification codes.
  • Duplicate-send protection so one press should not create two outgoing messages.
  • Admin view for all mailboxes and mailbox creation requests.

Creation Rules

Only muye@muye.dev can directly create a mailbox. Other users can send a request with the mailbox name they want and a short message.

Older Paths Removed

The phone-number/SMS verification path was removed. Recovery now uses email verification only.
