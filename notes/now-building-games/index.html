Games.

September 11, 2026

The games page is becoming a little pocket arcade: black background, touch-friendly controls, and quick games that do not need scores to be fun.

Current Set

The current games include Snake Lab, Minesweeper, 2048, Connect Four, Tic-Tac-Toe, Chess, Go, Checkers, Reversi, Battleship, Sudoku, Wordle, Lights Out, Memory Match, Hangman, Blackjack, and Rock Paper Scissors.

Design Rules

  • Phone and iPad friendly first.
  • No scoring pressure.
  • Simple controls that work with taps, swipes, long-press, right-click, and keyboards where useful.
  • Mostly black-background UI so the games feel like one place.

Next Ideas

More tiny games can join the same hub as long as they stay fast to open, easy to understand, and comfortable on a small screen.
