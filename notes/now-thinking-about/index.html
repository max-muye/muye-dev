Now thinking about

Muye.dev is now v1.2.4.

September 11, 2026

This note is the living place for what changed, what shipped, and what the site is slowly turning into.

Version List

v1.2.4 is the current version of muye.dev.

Versions use big.feature.fix: the last number is for small deploys, the middle number is for bigger updates, and the first number is for major site changes.

v1.2.4

  • Fixed the shared game play renderer so games like Blackjack load their play area again.

v1.2.3

  • Added a shared footer to static pages, app pages, games, auth pages, and LocalTalk Worker pages.

v1.2.2

  • Added game records, personal/global record notices, and sharing saved game records from the LocalTalk plus menu.

v1.2.1

  • Added master-language support to the new Games hub entries, game play pages, and Snake controls.

v1.2.0

  • Added admin approval for mailbox requests, with temporary password creation.
  • Added a footer language switch and expanded language support for auth pages around Clerk.

v1.1.0

  • Expanded Games with 20 playable entries, clearer how-to-play notes, and per-user saved progress on this browser.

v1.0.2

  • Made Mailbox follow the master language setting, including forms, folders, empty states, and admin labels.
  • Made LocalTalk understand every master language option while keeping its full English/Chinese wording.

v1.0.1

  • Added master-language translations for homepage cards, note rows, and the footer.

v1.0.0

  • Home page, profile, notes, and project hub.
  • LocalTalk chat through /talk and /api/talk.
  • Mailbox tools with Muye email, inbox, outbox, admin requests, and email-only password reset.
  • Games, Lambda, browser, coder, captcha, and installable app manifests.
  • Clerk sign-in on the main site and signed LocalTalk.
