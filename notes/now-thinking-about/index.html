Muye.dev is now v2.3.0.

September 19, 2026

This note is the living place for what changed, what shipped, and what the site is slowly turning into.

Version List

v2.3.0 is the current version of muye.dev.

Versions use major.normal.small: the first number is for big updates, the middle number is for normal updates, and the last number is for small fixes.

v2.3.0

Added functional MC3D redstone dust, toggleable levers, NOT gates, directional one-way gates, powered TNT fuses, chain explosions, and a phone-friendly scrolling hotbar.

v2.2.0

Made MC3D worlds expand with deterministic terrain chunks near the player, with the added land saved and restored with each world.

v2.1.4

Fixed MC3D left-click mining and right-click block placement when pointer lock is unavailable, including the in-app browser.

v2.1.3

Changed MC3D mouse-look to centered pointer lock, with Escape releasing the mouse and a click-to-continue prompt.

v2.1.2

Hid the mouse pointer while playing MC3D and restored it inside the world menu.

v2.1.1

Fixed MC3D forward and backward movement and made mouse movement turn the camera immediately.

v2.1.0

Added MC3D with generated 3D worlds, mining, building, desktop and touch controls, day and night, per-user browser saves, and ten-language support.

v2.0.0

Renamed the Misc section to Tools, moved the tool routes under /tools/, kept old links redirecting, and updated the Tools labels in all ten languages.

v1.3.7

  • Added a top-level /download/ page and moved LocalTalk downloads to /download/#localtalk.

v1.3.6

  • Added MC 2D water, lava, rain, improved bed sleeping, and new-world switches for slow/fast speed and survival/creative mode.

v1.3.5

  • Added separate MC 2D world slots with a load screen and automatic migration of the previous single save.
  • Added sand, glass, stone bricks, beds, climbable ladders, and zombie, spider, and slime mobs with distinct movement and drops.

v1.3.4

  • Made held-pointer mining follow the current block and cancel immediately when the pointer moves away.

v1.3.3

  • Expanded MC 2D into survival play with physical item drops, seeds and plant growth, food and hunger, hostile night mobs, health damage, and torch lighting.

v1.3.2

  • Added an MC 2D backpack with blocks, materials, tool equipping, touch controls, and a desktop B shortcut.

v1.3.1

  • Added timed block mining, wooden/stone/iron tools, iron ore, furnaces, and iron smelting to MC 2D.

v1.3.0

  • Added MC 2D: a generated mining and building world with touch controls, crafting, day and night, ten languages, and per-user browser saves.

v1.2.11

  • Added a password hash explainer page and fixed the password hash iteration input so custom values do not trigger the browser's invalid-value popup.

v1.2.10

  • Made homepage daily check-in visible only for signed-in users and saved each user's checked-in day count separately.

v1.2.9

  • Added 10-language names, descriptions, and how-to-play text for the newest 10 Games entries.

v1.2.8

  • Added 10 more phone-friendly games to the Games hub.

v1.2.7

  • Added shared 10-language support for notes and the CAPTCHA test page, plus a README rule for new pages.

v1.2.6

  • Added rotating homepage greeting messages and a browser-saved daily check-in.

v1.2.5

  • Translated the signed-in homepage hero greeting instead of leaving the biggest text as only “Hi”.

v1.2.4

  • Fixed the shared game play renderer so games like Blackjack load their play area again.

v1.2.3

  • Added a shared footer to static pages, app pages, games, auth pages, and LocalTalk Worker pages.

v1.2.2

  • Added game records, personal/global record notices, and sharing saved game records from the LocalTalk plus menu.

v1.2.1

  • Added master-language support to the new Games hub entries, game play pages, and Snake controls.

v1.2.0

  • Added admin approval for mailbox requests, with temporary password creation.
  • Added a footer language switch and expanded language support for auth pages around Clerk.

v1.1.0

  • Expanded Games with 20 playable entries, clearer how-to-play notes, and per-user saved progress on this browser.

v1.0.2

  • Made Mailbox follow the master language setting, including forms, folders, empty states, and admin labels.
  • Made LocalTalk understand every master language option while keeping its full English/Chinese wording.

v1.0.1

  • Added master-language translations for homepage cards, note rows, and the footer.

v1.0.0

  • Home page, profile, notes, and project hub.
  • LocalTalk chat through /talk and /api/talk.
  • Mailbox tools with Muye email, inbox, outbox, admin requests, and email-only password reset.
  • Games, Lambda, browser, coder, captcha, and installable app manifests.
  • Clerk sign-in on the main site and signed LocalTalk.
