Software taste

Small choices become a product's character.

July 29, 2026

Good software rarely announces every decision it makes. It gives the user a surface that feels calm because the details have already been considered.

Trust lives in the edges

Loading states, empty states, sensible defaults, and clear error messages are not decoration. They tell someone whether the system is paying attention.

The best interface choices reduce the number of tiny negotiations a person has to make. Less friction leaves more room for the work itself.
