Emoji Joiner

Combine emoji pieces with a zero-width joiner (ZWJ) to build a sequence such as 👩‍❤️‍👩. Everything runs in your browser.

Result

👩‍❤️‍👩

Why does it contain several characters?

A joined emoji can contain multiple Unicode code points: the visible emoji pieces plus U+200D, a zero-width joiner that asks a compatible system to display them as one symbol. The sequence may look different across platforms.
